# V17.1 — Schema synchronization stability release (summary)
- **Publish gate:** push validates every local schema first and never publishes invalid data.
- **One rule set** for import, Manual Schema Update, push and pull (`src/v17/sync/schemaFormat.ts`). Data is normalised (lossless legacy conversions, all reported) before it is validated.
- **Per-schema verdict:** valid repository schemas load; invalid ones are rejected individually with JSON paths. A valid local copy is never overwritten.
- **Recovery options:** Repair (with preview), Restore from repository, Review repaired repository copy, Publish my local copies, Download repository file, Validate repository file.
- **Other fixes:**
  - large (> 1 MB) repository files
  - backup of a corrupted local registry
  - precise GitHub error messages
  - schema-management results that stay visible
  - legacy names editable in Manual Schema Update
- **Root cause:** the V16 Manual Schema Update delete left dangling foreign keys, which were published without validation. See `ROOT_CAUSE_V17.1.md`.
