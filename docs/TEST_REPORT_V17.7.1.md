## Limitations of this validation
* GitHub, the central access service, the published site, GitHub Actions and Azure were **emulated or not reachable** — real-world behaviour (token scopes, SSO / Conditional Access, rate limits, CORS of the access service) is **unverified**.
* The 17 historical browser suites (`scripts/browser_test*.py`) were not in the supplied bundles and were **not run**; the V17.7 browser suite `browser_test_v177.py` was therefore not re-run. The V17.7 regression coverage that was run is the Node suite (320+ tests) plus the new browser suite's regression section.
* `npm ci` was **not run** (`package-lock.json` is absent from the package, as in V17.6.x — the npm registry is not reachable); TypeScript 5.8.3 was used directly from the environment. The project builds with its own build script (`scripts/build.mjs`); there is no Vite in this project, so no "Vite build" exists to run.
* A clipboard check in the browser worked with Chromium's permission grant; other browsers were not tested.
