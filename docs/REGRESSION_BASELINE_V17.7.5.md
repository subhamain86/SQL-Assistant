# Regression baseline — V17.7.5

* **Reference:** the V17.7.4 text bundles as supplied (359 files). The original V17.7.4 zip was not available, so the reference is a **rebuild**: three compiler files restored only at their recorded SHA-256, the favicon recovered from `dev-dist`, the two Python browser suites re-created, generated outputs rebuilt (`RECONSTRUCTED.txt` in the rollback zip). Before anything was changed, that reference was built and tested with **no npm, no node_modules and no `NODE_PATH`**: **427 of 428 Node tests passed**; the one failure is `test/v1763.test.mjs` "a rebuild keeps the published copy" — a **defect of V17.7.4** (the test symlinks a `node_modules` that a registry-free checkout does not have). V17.7.4's own report said 428/428 because the sandbox had a global `NODE_PATH` that hid it.

Taken **before the first V17.7.5 change**.
