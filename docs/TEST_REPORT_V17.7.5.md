## Defects found by these tests and fixed
* **V17.7.4 defect:** `test/v1763` needed a `node_modules` that a registry-free checkout does not have (it passed in V17.7.4 only because the sandbox had a global `NODE_PATH`). Fixed by copying the committed compiler instead; recorded in `test/fixtures/test-adaptations-v1775.json`.
* **Parser bug in the new guard** found by the PyYAML cross-check: a `name:` inside a step's `with:` block was read as the step's name. Fixed (only step-level keys count).
* **Documentation gap** found by the contract test: the broker artifact did not list `SQLA_MAX_WRITE_BYTES`, nor the analytics artifact `SQLA_ANALYTICS_ADMIN_PASSWORD`. Added.
* Smaller: a nested `node --test` inherited the parent's reporter context; a test pinned the version literal against the project's own test-design rule.

## Not run / not possible here
GitHub Actions itself (no workflow was executed by GitHub), a real GitHub Pages deployment, a real repository's permissions and rate limits, other browsers. PyYAML was available here; where it is not, the guard's strict text extractor is the only parser and the test says so.
